## 一、单项选择题（每小题 3 分，共 12 分）

1. 下列各组函数中表示同一函数的是（　　）
   A. f(x) = x，g(x) = (√x)<sup>2</sup>
   B. f(x) = |x|，g(x) = √(x<sup>2</sup>)
   C. f(x) = ln x<sup>2</sup>，g(x) = 2ln x
   D. f(x) = x，g(x) = ln(e<sup>x</sup>)

2. 当 x→0 时，与 x 等价的无穷小是（　　）
   A. sin x　　　B. 1 - cos x　　　C. x·sin x　　　D. √(1 + x) - 1

3. 函数 f(x) = (x<sup>2</sup> - 1)/(x - 1) 在 x = 1 处的间断点类型是（　　）
   A. 可去间断点　　　B. 跳跃间断点　　　C. 无穷间断点　　　D. 振荡间断点

4. 计算 lim(x→1) (x<sup>3</sup> - 1)/(x<sup>2</sup> - 1)，结果为（　　）
   A. 1　　　B. 3/2　　　C. 2　　　D. 不存在

   lim(x→2) (x<super>2</super> - 4)/(x - 2) = ?

# 答案与评分标准

## 一、单项选择题（每小题 3 分，共 12 分）

<b>A1.</b> D　ln(e<sup>x</sup>) = x 对一切实数成立；A、B、C 的定义域或对应法则不同。　给分点：概念判断（3 分）
<b>A2.</b> A　sin x ~ x；1 - cos x 是二阶；x·sin x 是二阶；√(1 + x) - 1 ~ x/2。　给分点：等价无穷小（3 分）
<b>A3.</b> A　x ≠ 1 时 f(x) = x + 1 → 2，而在 x = 1 无定义，为可去间断点。　给分点：间断点分类（3 分）
<b>A4.</b> B　因式分解：(x - 1)(x<sup>2</sup> + x + 1)/[(x - 1)(x + 1)] = (x<sup>2</sup> + x + 1)/(x + 1) → 3/2。　给分点：因式分解与极限（3 分）

## 二、计算题（每小题 6 分，共 12 分）

<b>B1.</b> 4；在 x = 2 处无定义，但极限存在，为可去间断点。　x ≠ 2 时 (x<sup>2</sup> - 4)/(x - 2) = x + 2 → 4。　给分点：因式分解或代入化简（3 分）；求极限值（2 分）；指出可去间断点（1 分）
<b>B2.</b> e<sup>2</sup>　底数写成 1 + 2/(x - 1)，指数 x 乘无穷小 2/(x - 1) 趋于 2，故极限为 e<sup>2</sup>。　给分点：凑重要极限形式（4 分）；指数处理与结果（2 分）

## 三、证明题（6 分）

<b>C1.</b> 提示：|(2n + 1)/(n + 1) - 2| = 1/(n + 1) < ε，取 N 为 1/ε 向上取整。　完整写法见答案：任给 ε > 0 → 作差化简 → 反解 → 取 N → 结论句。　给分点：任给 ε > 0（1 分）；作差并化简（2 分）；反解并取 N（2 分）；结论句（1 分）　证明自查：前提逐条核对：极限过程是 n→∞，ε > 0 任意给定，N 必须是正整数；作差后化简到只含 n 的表达式；反解出 n 的不等式并取 N；结论句写全：当 n > N 时恒有 |·| < ε
