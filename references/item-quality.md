# 命题质量与难度分层

## 1. 原创仿真 vs 复制真题

- 允许：沿用真题的**题型、考点组合、问法角度、分值**。
- 禁止：连续两句以上与真题同表述；直接使用真题的数据组合（换数字、换函数外壳）。
- 卷首必须标注"原创仿真卷，非官方真题"。

## 2. 客观题（选择/填空）

**选择题的四个选项都要有诊断意义**——错误选项要对应一类真实错误：

| 干扰项类型 | 例（等价无穷小） | 诊断什么 |
| --- | --- | --- |
| 概念偷换 | 把"无穷小量"当成很小的常数 | 没分清"变量"与"数" |
| 方向反转 | 把充分条件当必要条件 | 条件方向不清 |
| 条件遗漏 | 定义域漏掉分母为零/对数真数 | 计算习惯不严 |
| 数值算错 | 系数没跟上（sin 2x/x 写成 1） | 公式记不牢 |

选项长度尽量接近，避免"最长的是答案"这种可蒙规律。

填空题适合考：定义域、单步计算、阶数、定参（使连续/使极限存在）。每题只留**一个明确答案**。

## 3. 主观题（计算/证明/综合）

- 计算题：要求"写出关键步骤"；答案给可评分的步骤链，不跳关键变形。
- 证明题：答案写满"要证什么 → 化简/构造 → 反解或归纳 → 结论句"，并给分点。
- 综合题：优先设计成**多小问**（求极限 → 定参数 → 判断间断点类型），能定位到具体能力。
- "命题真假 + 举反例"很好用：一次考出"会不会证"和"会不会破"。

## 4. 难度分层

| 档位 | 判据 | 诊断卷占比 |
| --- | --- | ---: |
| 基础 | 单考点、直接套定义或公式，两步内完成 | 约 40% |
| 中等 | 需要一步转化/组合（有理化、等价替换、凑形、夹逼两端） | 约 40% |
| 挑战 | 多步推理、需要构造或反例、易混概念对比 | 约 20% |

## 5. 常见坑

- **超纲工具**：用洛必达/泰勒/变上限积分考"第一章"。要么换掉，要么明确标注"挑战题（需第 X 章）"。
- **难度全堆在一节**：诊断没有分辨率。
- **只给答案不给给分点**：无法自查"哪一步丢分"。
- **答案和题目混排**：破坏自测价值。
- **数字太丑**：优先心算可验的数据，把时间花在方法上。

## 6. 给分点（rubric）写法

- 每条 ≥5 分的题都要有 rubric，且**合计必须等于该题分值**（`--check-spec` 会报错）。
- 每条写成"可观察的动作 + 分值"，例如：任给 ε（1 分）/ 作差化简（2 分）/ 反解取 N（2 分）/ 结论句（1 分）。
- 不要写"过程 3 分"这种无法执行的口径；阅卷人需要能对号入座。
- 客观题也要写一条 rubric（如"概念判断 3 分"），保证答案区结构统一。

## 7. 数值复核（numeric_check）

计算题的答案可以用一条表达式独立复核：

```json
"numeric_check": {"expr": "((x + 1)/(x - 1))**x", "at": [1000, 10000],
                  "expected": 7.389056, "rtol": 0.01}
```

- `at` 取靠近目标点的样本（极限题取足够大的值或足够近的值）。
- 只允许 `x`、数字、`+ - * / ** %` 与白名单函数（sin/cos/exp/log/sqrt/...）；不支持任意代码。
- 证明题没有数值复核——这是工具的边界，必须人工核对答案。

## 8. 时间预算

- 每题写 `time_min`，全卷之和与 `meta.duration_min` 相差不超过 20%（或 5 分钟）时只警告，超过则需调整。
- 选择题 2–5 分钟、计算题 6–12 分钟、证明题 7–15 分钟是常见量级；按目标考试的真实节奏标定。
