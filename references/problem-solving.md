# 卡住时的自主求解循环（证明题 / 定理）

## 触发条件

出现下列任一情况，先停下来检索，不要凭记忆写：

- 定理的**条件**记不准（如"闭区间连续"还是"开区间连续"）；
- 知道结论，但**构造**（辅助函数、放缩、取 ε/N）想不出来；
- 自己算出的答案与直觉/数值抽样冲突；
- 找不到反例，或不确定某个反例是否合法；
- 两道题的条件看起来相同，结论却不同。

## 五步循环

1. **重述目标**：要证什么？已知什么？卡在定义 / 条件 / 构造 / 结论哪一步？
2. **检索**：用"定理名 + 条件 / 反例 / proof"作查询词；优先官方教材页、大学课程页、百科条目。
3. **交叉核对两个独立来源**：逐条比对定理表述与前提条件；不一致就以更权威者为准并标注。
4. **本地自检**：代一个小例子、取极端值、或用数值抽样（`numeric_check`）验证合理性。
5. **留痕**：记录 `title / url / accessed(YYYY-MM-DD) / used_for / quote`（quote 必须是页面上真实存在的原文，≥10 字）。仍不能确定时，标 `uncertain: true` 并向用户提问；**不许编造定理**。
6. **复核链接**：运行 `scripts/check_sources.py --spec paper.json --allow-blocked`，确认页面可达且 quote 命中。证明题至少 2 个独立来源，否则 `--check-spec` 直接报错。

## 查询词模板

| 场景 | 查询词 |
| --- | --- |
| 定义记不准 | `"epsilon N definition" sequence limit` / `数列极限 ε-N 定义 条件` |
| 定理条件 | `<定理名> conditions proof` / `<定理名> 前提 条件` |
| 找反例 | `<命题> counterexample` / `<命题> 反例` |
| 构造辅助函数 | `<结论> auxiliary function proof` / `<结论> 辅助函数 证明` |
| 验证答案 | `limit calculator step by step`（只作数值参考，不替代证明） |

## 来源分级

| 级别 | 例子 | 用法 |
| --- | --- | --- |
| A | 教材/出版社官方页、大学课程讲义（MIT OCW、OpenStax） | 可直接作为依据 |
| B | 百科（Wikipedia、Encyclopedia of Math）、LibreTexts | 需与 A 或另一 B 交叉 |
| C | 论坛、问答、博客 | 只用于找思路，不写进 `sources` |

## 证明题自查清单（写进 `proof_check`）

1. 前提逐条核对（定义域、闭/开区间、连续性、单调性、正负号）。
2. 构造/放缩的理由：为什么想到它？不构造会卡在哪？
3. 不等号方向、取整、端点是否包含。
4. 结论句是否覆盖"对所有 n > N / 所有 x 属于区间"。
5. 找一个边界情形（等号、零、端点）检验是否仍成立。

## 不要做

- ❌ 只引用搜索摘要，不打开页面核对；
- ❌ 用问答/论坛作为唯一来源；
- ❌ 把"定理用不上"写成"结论不成立"；
- ❌ 不确定却标 `uncertain: false`。
